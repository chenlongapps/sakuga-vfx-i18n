# 进度条

[English](README.md) · **简体中文** · [日本語](README.ja.md)

一条进度条，前端骑着一团风暴云。云会随着进度增长而变大，加载突进时云顶向后拖；云丝从云上撕裂，速度线跟在后面。进度条下方自行绘出地面线，边缘经过时石子被带起。进度开始后「ゴゴゴゴ」隆隆作响。完成时，进度条背后炸开冲击波并出现「ドン！」，上方落下对勾，地面留下两朵小云。

## 运行

```sh
python3 -m http.server 8000     # 在仓库目录中运行
# 打开 http://localhost:8000/progress/
```

页面会播放一次模拟加载。拖动下方的滑块可以手动控制。

## 使用

```html
<script src="progress.js"></script>
<sakuga-progress label="正在上传照片"></sakuga-progress>
```

```js
upload.onprogress = (e) => el.set(e.loaded / e.total);
el.addEventListener('sakuga:done', () => showResult());
el.set(0.5, true);   // 直接到达，无缓动
el.reset();          // 回到 0，准备下一个任务
el.value; el.done;
```

| 属性 | 作用 | 默认值 |
|---|---|---|
| `label` | 屏幕阅读器读取的名称 | 正在加载 |
| `value` | 0 到 1 的进度 | 0 |
| `done-label` | 完成时的文字 | 已完成 ✓ |
| `demo` | 循环播放模拟加载；点击可重新开始 | 关闭 |

- **一个数字驱动全部。** 进度条会缓动到目标值（每秒至少 12%，最多 90%），所以跳跃式变化也会被云朵跟随。云的速度和拖拽感来自进度条的实际移动速度，因此上传停滞时云也会静止。
- **`sakuga:done` 只触发一次，** 当进度条本身到达终点时触发，略晚于你调用 `set(1)`。回退（设置更小的值）会清除完成状态。
- **尺寸：** 宽 280 像素（`--sk-progress-width`）。上方为云保留 70 像素，下方为地面和数字保留约 110 像素。
- **离开屏幕后停止绘制。** 进度条仍会继续填充。
- **不要在生产环境使用 `demo`。**

## 限制

- **没有不确定状态。** 没有数字时停在 0。
- **没有失败状态。** 如果任务失败，请在旁边提示并调用 `reset()`。

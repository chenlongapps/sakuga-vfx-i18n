# プログレスバー

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

先端に雷雲が乗ったプログレスバーです。バーが進むにつれて雲が大きくなり、読み込みが急進すると雲の頂部が後ろへ引きます。雲の切れ端がちぎれ、スピード線が後を追います。バーの下には地面の線が描かれ、先端が通過すると小石が浮き上がります。読み込みが始まると「ゴゴゴゴ」が鳴ります。完了時にはバーの背後で衝撃波と「ドン！」が弾け、上にチェックが落ち、地面に小さな雲が 2 つ残ります。

## 実行

```sh
python3 -m http.server 8000     # リポジトリのフォルダで実行
# http://localhost:8000/progress/ を開く
```

ページは模擬的な読み込みを再生します。下のスライダーをドラッグすると手動で進められます。

## 使い方

```html
<script src="progress.js"></script>
<sakuga-progress label="写真をアップロード中"></sakuga-progress>
```

```js
upload.onprogress = (e) => el.set(e.loaded / e.total);
el.addEventListener('sakuga:done', () => showResult());
el.set(0.5, true);   // 緩和なしで直接移動
el.reset();          // 次のタスク用に 0 へ戻す
el.value; el.done;
```

| 属性 | 設定内容 | 既定値 |
|---|---|---|
| `label` | スクリーンリーダーが読み上げる名前 | 読み込み中 |
| `value` | 0〜1 の進捗 | 0 |
| `done-label` | 完了時の文字 | 完了 ✓ |
| `demo` | 模擬読み込みをループ再生。クリックで最初から | オフ |

- **1 つの数値で動きます。** バーは与えた値へ緩やかに近づきます（1 秒あたり最低 12%、最大 90%）。そのため急な変化でも雲が追従します。雲の速度と引っ張りはバーの実際の移動速度から決まるので、アップロードが止まれば雲も止まります。
- **`sakuga:done` は 1 回だけ発火します。** バー自体が終端に到達したときで、`set(1)` を呼んだ少し後です。値を小さくして戻すと完了状態は解除されます。
- **サイズ：** 幅 280 ピクセル（`--sk-progress-width`）。上に雲用の 70 ピクセル、下に地面と数値用の約 110 ピクセルを確保します。
- **画面外では描画を停止します。** バーは引き続き進みます。
- **`demo` は本番環境で使わないでください。**

## 制限

- **不確定状態はありません。** 数値がない場合は 0 のままです。
- **失敗状態はありません。** タスクが失敗した場合は、横に表示して `reset()` を呼んでください。

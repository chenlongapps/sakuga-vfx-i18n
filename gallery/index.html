Sakuga VFX

Twelve demos of ordinary controls that react like anime: squash and overshoot on springs, and drawn effects (smoke, impact bursts, splashes, slashes) with manga sound-effect lettering. Each component is a single file with no dependencies.

Upstream project ↗ MIT license

Effects are drawn on one canvas over the page and switch off for prefers-reduced-motion . Every colour is a --sk-* variable you can override.

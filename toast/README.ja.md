# トースト通知

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

左から残像を引いて飛び込み、後ろにスピード線を伴い、砂ぼこりの中で点線の描き文字「ズザッ」とともに着地し、揺れたあと縮んで消える通知です。

## 実行

```sh
python3 -m http.server 8000     # リポジトリのフォルダで実行
# http://localhost:8000/toast/ を開く
```

## 使い方

```html
<script src="toast.js"></script>
<sakuga-toast style="position: fixed; left: 24px; bottom: 24px"></sakuga-toast>
```

```js
el.show('保存しました！');
el.hide();
el.open;    // 表示中は true
```

| 属性 | 設定内容 | 既定値 |
|---|---|---|
| `duration` | 表示し続ける秒数 | 2.6 |
| `message` | `show()` にメッセージを渡さないときの文字 | 保存しました！ |
| `dismiss-label` | ✕ ボタンのアクセシブル名 | 通知を閉じる |

- **通知を表示したい位置に要素を置きます。** サイズは 236 × 56 ピクセルで、非表示のときもその領域を確保します。通常は画面の隅に固定するなど、自分で配置してください。
- **メッセージは `role="status"` 領域内にある**ため、スクリーンリーダーが読み上げます。✕ は本物のボタンです。
- **一度に 1 つだけ表示します。** もう一度 `show()` を呼ぶとメッセージが置き換わり、入場アニメーションが最初から再生されます。

## 制限

- **複数の通知を積み重ねる機能はなく、** エラーや警告などの種類もありません。アイコンは常にチェックです。
- **1 行のみです。** 長いメッセージは省略記号で切り取られます。

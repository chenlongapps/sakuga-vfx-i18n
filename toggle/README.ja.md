# トグルスイッチ

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

押すとスイッチがつぶれ、その後つまみが伸びてインクの残像を引きます。オンにすると、つまみの後ろで水の幕が盛り上がり、丸い水滴を飛ばします。液体が満ちるにつれて波頭はトラックへ折り返します。オフにすると液体が引き、反対側で低い波と鋭い横方向の破片が跳ねます。どちらの衝撃でもローカライズされた「カチッ」が出て、最後に光ります。

## 実行

```sh
python3 -m http.server 8000     # リポジトリのフォルダで実行
# http://localhost:8000/toggle/ を開く
```

## 使い方

```html
<script src="toggle.js"></script>
<sakuga-toggle label="通知"></sakuga-toggle>
<sakuga-toggle label="ダークモード" checked name="dark"></sakuga-toggle>
```

```js
el.addEventListener('change', () => console.log(el.checked));
el.checked = true;    // コードから設定：アニメーションなしで終点へ
el.flip();            // コードから切り替え：アニメーション付き
```

| 属性 | 設定内容 | 既定値 |
|---|---|---|
| `label` | スクリーンリーダーが読み上げる名前 | トグル |
| `checked` | オン | オフ |
| `name`、`value` | オンのときフォームと一緒に送信。チェックボックスと同じ | 値 `on` |
| `disabled` | 切り替え不可 | オフ |

- Shadow ボタンには `role="switch"` が付きます。スペースキーと Enter キーで切り替わり、`aria-checked` が現在値を反映します。
- ヒット領域は 108 × 54 CSS ピクセルで、108 × 182 のホスト中央にあります。ほかのコントロールと位置を揃えるためです。上下約 64 ピクセル（左右は各 21 ピクセル）はエフェクト用に空けています。
- ユーザー操作または `flip()` でアニメーションが再生され、バブリングする `change` イベントが発行されます。`checked` を直接設定すると、要求した状態がすぐに描画されます。
- フォームのリセットで、スイッチの初期チェック状態が復元されます。無効なスイッチまたは fieldset は、このコントロールの操作とフォーム送信をブロックします。

## 描画とテーマ

- 筐体、ダイヤル、残像、液体は Canvas 2D のパスで描画されます。ばねは共通の `requestAnimationFrame` クロックの経過時間を使うため、素早い切り替えでも現在位置と運動量が保たれます。
- `<html lang>` を `en`、`zh-CN`、`ja` のいずれかにすると、衝撃の描き文字が切り替わります。
- `--sk-ink` で輪郭、`--sk-card` と `--sk-soft` でダイヤル、`--sk-track` で空のトラック、`--sk-pri` で液体、`--sk-acc` で衝撃の描き文字とフォーカスリングをテーマ設定できます。共有パーティクルはプロジェクトのエフェクトパレットを使います。
- 視差効果を減らす設定が有効な場合、スイッチは即座に更新され、エフェクトはスキップされます。
- 単体スクリプトは共有コアと描き文字を含めて約 100 KiB です。

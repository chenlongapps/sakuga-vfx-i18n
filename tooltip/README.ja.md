# ツールチップ

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

ヘルプボタンで、ヒントが吹き出しのように飛び出します。両側に煙、ボタンの上に輪、角にくさびが出て、中空の「カチッ」が鳴ります。

## 実行

```sh
python3 -m http.server 8000     # リポジトリのフォルダで実行
# http://localhost:8000/tooltip/ を開く
```

## 使い方

```html
<script src="tooltip.js"></script>
<sakuga-tooltip text="領収書の送付にのみ使用します。" label="必要な理由"></sakuga-tooltip>
<sakuga-tooltip text="キーボードショートカット">i</sakuga-tooltip>
```

```js
el.show(); el.hide(); el.open;
```

| 属性 | 設定内容 | 既定値 |
|---|---|---|
| `text` | ヒント | 操作のヒントです！ |
| `label` | スクリーンリーダーが読み上げるボタン名 | ヘルプ |

- **マウスホバー、フォーカス、タップで開き、** Escape で閉じます。ヒントは `aria-describedby` でボタンに関連付けられます。
- **要素内の内容がボタンの「?」を置き換えます。**
- **ヒントは最大幅 220 ピクセル** で折り返します。ボタンの上に開き、要素はそのために上に 60 ピクセルを確保します。

## 制限

- **常に上に開きます。** スペースがない場合でも下へ反転しません。
- **ほかの要素を指すことはできません。** ボタン自体がトリガーです。

# 按钮

[English](README.md) · **简体中文** · [日本語](README.ja.md)

一个像动画冲击帧一样反应的按钮。按下时它会压扁，上方弹出楔形；松手后它反转一帧并倾斜，背后炸开带碎晶和四团云的尖刺冲击波，「ドン！」落在上方。随后它弹高，三圈烟雾飘散。操作成功后调用 `el.done()`，一个带闪光的对勾会落在按钮上。

次要变体更安静：轻微压扁，角落出现三道楔形。

这是仓库中十一个组件之一。每个组件都遵循同一思路（普通控件，动画式反应），只是控件不同。

## 运行

```sh
python3 -m http.server 8000     # 在仓库目录中运行
# 打开 http://localhost:8000/button/
```

`?embed=1` 会隐藏页面标题。

## 使用

`button.js` 就是整个组件：单文件，无依赖。

```html
<script src="button.js"></script>
<sakuga-button>确认</sakuga-button>
<sakuga-button variant="secondary">取消</sakuga-button>
```

```js
const el = document.querySelector('sakuga-button');
el.addEventListener('click', async () => {
  await save();
  el.done();          // 对勾带着闪光落上去，1.8 秒后消失
});
el.done(0);           // 也可以让对勾保留到下次点击
el.impact();          // 不点击也播放一次点击反应
el.disabled = true;
```

| 属性 | 作用 | 默认值 |
|---|---|---|
| `variant` | 设为 `secondary` 使用安静样式 | 主按钮 |
| `type` | 设为 `submit` 时提交所在表单 | `button` |
| `disabled` | 与原生按钮一致 | 关闭 |

- **元素内的文本就是标签。** Shadow DOM 中是真正的 `<button>`，因此可以获得焦点、响应空格和回车，点击也会传到你的监听器。
- **`done()` 由你决定何时调用。** 点击本身总会播放冲击动效；对勾才表示操作成功，所以只在成功时调用。
- **样式：** `sakuga-button::part(button)` 可以访问内部按钮。

## 交互过程

| 你的操作 | 组件反应 |
|---|---|
| 按下 | 高度压到一半、宽度增加四分之一；上方出现三道楔形，两侧出现晃动线，下方出现一条短线 |
| 松手 | 冲击帧：墨色背景持续 0.19 秒，倾斜 5°，放大到 124%。背后炸开 98 像素的冲击波，十一片碎晶飞出，四团云从角落滚出，「ドン！」落在上方 |
| 0.2 秒后 | 弹高，两侧出现晃动线，三圈由大到小的烟雾向右上飘散，底部掉落碎屑 |
| `done()` | 标签末端长出一个粉色对勾，伴随闪光和角落的两道楔形 |

## 限制

- **背后的冲击波可能被裁切。** 它画在元素内部的画布上，画布会向四周延伸 160 像素；如果父元素设置了 `overflow: hidden`，就会被裁掉。其他特效都画在页面级画布上，不会被裁切。
- **只有一种标签尺寸。** 内边距和字号固定，没有小号或大号。
- **仅在无头 Chromium 中验证**，使用真实触摸和按键事件；尚未在 Safari、Firefox 或屏幕阅读器中测试。

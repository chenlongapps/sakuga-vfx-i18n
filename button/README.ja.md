# ボタン

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

アニメのインパクトフレームのように反応するボタンです。押すと平たくつぶれ、上にくさびが出ます。離すと 1 フレームだけ反転して傾き、背後で結晶と 4 つの雲を伴うトゲのある衝撃波が弾け、「ドン！」が上に落ちます。その後、高く跳ね上がり、3 つの煙の輪が漂います。操作が成功したら `el.done()` を呼ぶと、光を伴うチェックがボタンに乗ります。

セカンダリバリアントはより静かで、小さくつぶれ、角に 3 本のくさびが出ます。

このリポジトリの 11 ファイルの 1 つです。どれも同じ考え方（普通のコントロール＋アニメ的な反応）で、コントロールだけが異なります。

## 実行

```sh
python3 -m http.server 8000     # リポジトリのフォルダで実行
# http://localhost:8000/button/ を開く
```

`?embed=1` を付けると見出しが非表示になります。

## 使い方

`button.js` がコンポーネント全体です。1 ファイルで依存関係はありません。

```html
<script src="button.js"></script>
<sakuga-button>確定</sakuga-button>
<sakuga-button variant="secondary">キャンセル</sakuga-button>
```

```js
const el = document.querySelector('sakuga-button');
el.addEventListener('click', async () => {
  await save();
  el.done();          // 光を伴うチェックが乗り、1.8 秒後に消えます
});
el.done(0);           // 次のクリックまでチェックを残すこともできます
el.impact();          // クリックなしでクリック反応を再生します
el.disabled = true;
```

| 属性 | 設定内容 | 既定値 |
|---|---|---|
| `variant` | `secondary` で静かなスタイル | プライマリ |
| `type` | `submit` で所属フォームを送信 | `button` |
| `disabled` | ネイティブのボタンと同じ | オフ |

- **要素内のテキストがラベルです。** Shadow DOM 内は本物の `<button>` なので、フォーカス、スペースキー、Enter キーに対応し、クリックはあなたのリスナーまで届きます。
- **`done()` は任意のタイミングで呼びます。** クリック自体は必ずインパクトを再生します。チェックは成功を示すものなので、成功したときだけ呼んでください。
- **スタイル：** `sakuga-button::part(button)` で内部のボタンにアクセスできます。

## 動作

| 操作 | 反応 |
|---|---|
| 押す | 高さが半分、幅が 4 分の 1 広がります。上に 3 本のくさび、両側に揺れ線、下に短い線が出ます |
| 離す | インパクトフレーム：インク色の背景が 0.19 秒、5° 傾き、124% まで膨らみます。背後で 98 ピクセルの衝撃波が弾け、11 個の結晶が飛び、4 つの雲が角から転がり出て、「ドン！」が上に落ちます |
| 0.2 秒後 | 高く跳ね上がり、両側に揺れ線、大小 3 つの煙の輪が右上へ漂い、下から欠片が落ちます |
| `done()` | ラベルの端にピンクのチェックが伸び、光と角の 2 本のくさびが付きます |

## 制限

- **背後の衝撃波は切り取られることがあります。** 要素内のキャンバスに描かれ、キャンバスは各辺の 160 ピクセル外側まで伸びます。親要素が `overflow: hidden` だと切り取られます。それ以外のエフェクトはページ全体のキャンバスに描かれるため、切り取られません。
- **ラベルサイズは 1 種類だけです。** 余白と文字サイズは固定で、小さい／大きいサイズはありません。
- **ヘッドレス Chromium で確認済み**です。実際のタッチとキーイベントを使いましたが、Safari、Firefox、スクリーンリーダーでは未検証です。
